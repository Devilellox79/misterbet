# 🎩⚽ MisterBet

**La Web App che ti aiuta a scommettere con la testa, non con la pancia.**

## 🎯 Cos'è MisterBet?

MisterBet è un'applicazione web che analizza le partite di calcio usando un modello matematico avanzato (Dixon-Coles + Comparazioni Affini) per trovare le migliori opportunità di scommessa basate sui dati, non sulle sensazioni.

## 🚀 Funzionalità Principali

- ✅ **Semaforo Visivo:** Verde = valore, Rosso = trappola
- ✅ **Top 3 Occasioni del Giorno:** Le migliori scommesse selezionate automaticamente
- ✅ **Cluster Storici:** Validazione dei segnali con dati degli ultimi 10-20 anni
- ✅ **15 Campionati:** Dai Top 5 europei alle coppe, fino ai campionati emergenti

## 🛠️ Stack Tecnologico

**Backend:**
- Python 3.10+
- FastAPI (API)
- Pandas (dati)
- Scikit-learn (machine learning)

**Frontend:**
- React/Next.js
- Tailwind CSS (styling)
- Deploy su Netlify

## 📊 Fonti Dati

- **Storico:** football-data.co.uk (CSV gratuiti)
- **Quote live:** The Odds API / API-Football (piano gratuito)
